# omni_v0.2fp: отчёт (wake word «Омни», данные только с коммерчески чистыми лицензиями)

Дата: 2026-11-23. Модель: `app/src/main/assets/wakeword/omni_v0.2fp.onnx` (857 КБ,
sha256 в `SHA256SUMS` и `ModelDigests.kt`). Голова-классификатор поверх
melspectrogram + embedding openWakeWord (вход `[1,16,96]`, выход `[1,1]`), рабочий
порог **0.5**, patience 2.

## Зачем переобучали

Первый прогон v0.2fp использовал голоса Piper с некоммерческими или неясными
лицензиями датасетов. Приложение платное, поэтому модель переобучена только на
голосах, чьи корпуса разрешают коммерческое использование. Лицензии проверены по
`MODEL_CARD` каждого голоса в `huggingface.co/rhasspy/piper-voices` (2026-11-23).

| Голос | Лицензия корпуса (из MODEL_CARD) | Вердикт |
|---|---|---|
| ru_RU-denis, ru_RU-dmitri | CC0 (OHF-Voice/voice-datasets) | можно |
| en_GB-vctk (109 дикторов) | CC BY 4.0 | можно, нужна атрибуция |
| kk_KZ-raya, kk_KZ-iseke | CC BY 4.0 (IS2AI) | можно, нужна атрибуция |
| en_US-l2arctic | CC BY-NC 4.0 | **нельзя** |
| en_US-ryan, tr_TR-dfki, ru_RU-ruslan | CC BY-NC-SA 4.0 | **нельзя** |
| en_US-lessac | исследовательская лицензия Blizzard 2013 | **нельзя** |
| ru_RU-irina | «Unknown» | **нельзя** (не подтверждена) |
| en_GB-jenny_dioco, en_GB-alan, en_US-amy | «See URL», нестандартная лицензия | исключены (не подтверждена) |
| en_GB-northern_english_male | CC BY-SA | исключён (share-alike) |
| en_GB-alba, en_US-libritts_r | CC BY 4.0 | чистые, но локальные файлы оказались обрезаны, не использовались |

Первый прогон v0.2fp (метрики 0.919 / 28 / 203 из задачи) обучался на l2arctic,
ryan, lessac, irina, dfki и тестировался на jenny, ruslan, l2arctic: **его
подключать нельзя**. Прежняя `omni_v0.1` тоже обучалась на lessac, ryan, alan,
irina, поэтому из APK убрана. Предобученные модели openWakeWord
(`hey_jarvis_v0.1.onnx`) по README проекта лицензированы CC BY-NC-SA 4.0 и тоже
убраны (код их не загружал). melspectrogram/embedding остаются (embedding Google,
Apache 2.0).

## Данные (training/gen_raw_v2.py, CATALOG)

- Train: ru denis (500 позитивов / 300 негативов), en vctk (дикторы с
  `speaker_id % 7 != 3`, 400 / 400), kk raya (100 / 100), живой голос владельца
  (12 train-клипов, 372 клипа с вариантами аугментации, `live_augment.py`).
- Test (speaker-disjoint): ru dmitri (120 / 60), en vctk, дикторы `% 7 == 3`
  (80 / 40), kk iseke (80 / 40): 280 позитивов, 140 негативов.
- Живой тест: 4 отложенных клипа владельца (`owner_003/007/011/014`), в обучение
  не входили.
- Шум и фоны: только синтетический цветной шум и склейки обучающих негативов,
  сторонних корпусов фона нет.
- Признаки: `make_features_v02.py --rounds 6`: 6000 позитивов (синтетика) +
  1860 (живые), 4800 негативов-окон.
- Валидация для отбора чекпойнтов (не пересекается с train и тестом):
  `gen_hardneg_val.py` + `make_val_v02.py` (2022 окна трудных негативов из
  337 клипов, поток речи+шума 0.32 ч).

Обучение: `train_fpfix.py --seed 2024` (25000 + 3000 шагов, CPU, около 10 минут),
эталон отбора: v0.1 при пороге 0.5. Порог и чекпойнты выбираются так, чтобы FP на
валидации были не хуже v0.1.

## Метрики: v0.1 против v0.2fp (чистый тест, порог 0.5)

| Метрика | v0.1 | v0.2fp |
|---|---|---|
| Стриминговый recall (eval_streaming, 280 клипов) | 229/280 = 0.82 | 228/280 = 0.81 |
| Стриминговый FP на негативах (140 клипов) | 20 | 19 |
| Recall по окнам (positive_features_test) | 0.457 | 0.550 |
| FP на трудных негативах валидации (2022 окна) | 146 | 106 |
| FP/ч на потоке валидации | 228 | 197 |
| FP/ч на fp_stream (0.27 ч) | 184 | 180 |
| Живые отложенные клипы владельца (silence/quiet/noisy) | 3/4 | **4/4** |

При пороге 0.4 стриминговый recall v0.2fp 0.857 при FP 20 (v0.1: 0.839 при 27).
v0.1 на этом тесте в выигрыше: она обучалась на голосе dmitri, который теперь
тестовый, а v0.2fp его не видела.

Прежние цифры задачи (0.919 против 0.831) относятся к первому прогону на другом
тесте и в этот отчёт не переносятся.

### Стабильность

Тот же рецепт, seed 1 и 7: живые клипы 4/4 у всех, FP на валидации заметно ниже
v0.1 (61 против 146 окон; 103-109 против 228 FP/ч), но recall по окнам при
пороге 0.5 меньше (0.44 и 0.41 против 0.55 у seed 2024 и 0.457 у v0.1).
Выбор seed 2024 сделан по валидации, это немного оптимистично. Порог 0.5 для
seed-разброса можно считать «безопасным по ложным срабатываниям, recall зависит
от обучения».

## Ограничения

- Живых клипов для проверки всего 4 (один владелец); живых негативов и записей
  фона (дом, улица, ТВ, ветер) нет, FP/ч считаются на синтетике (около 200 в час:
  это в абсолютных числах много, пригодность подтверждается только полевым
  тестом).
- Русский синтез в обучении ограничен одним голосом denis (плюс живой голос);
  второй русский голос dmitri отдан в тест. Туркменского, узбекского и
  турецкого в данных нет (турецкий голос dfki NC).
- По умолчанию в приложении слушает фраза «Окей, Омни» на sherpa-onnx; эта модель
  работает при выборе движка LEGACY_OMNI (админ).
- Нужен полевой замер на устройстве (`device-validation/06-wakeword-metrics.sh`).

## Воспроизведение

```
PIPER_VOICES=<папка голосов> python training/gen_raw_v2.py --out <raw>
python training/live_augment.py augment --clips <clips> --manifest <manifest> --raw <raw> --variants 30
python training/make_features_v02.py --raw <raw> --out <features> --rounds 6
PIPER_VOICES=<...> python training/gen_hardneg_val.py <raw_hn> 150
OMNI_FEATURES=<features> python training/make_val_v02.py hn <raw_hn> <hn.npy> 6
OMNI_FEATURES=<features> python training/make_val_v02.py stream <dir с raw_hn>
python training/train_fpfix.py --features <features> --out <out> --version v0.2fp \
    --ref-model <omni_v0.1.onnx из git: ce33434f> --val-neg <hn.npy> --val-stream <val_stream.npy>
```

Данные владельца, аудио и признаки в репозиторий не входят.
